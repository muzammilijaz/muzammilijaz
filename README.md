## ⬇️ ODM — Open Download Manager

### Free & Open Source IDM Alternative for Windows

**ODM (Open Download Manager)** is a modern desktop download manager built with **Rust, Tauri and React**.

It provides high-speed downloads, browser integration and video downloading without requiring proprietary download-manager software.

**Features**

* ⚡ Multi-connection chunked downloads
* ⏸ Pause and resume downloads
* 🔁 Automatic retry and recovery
* 📊 Bandwidth throttling
* 🎥 HLS and DASH streaming downloads
* 📺 YouTube, TikTok, Instagram and other video downloads
* 🎞 Video quality selection from **144p to 4K**
* 🌐 Chrome / Edge browser extension
* 🖱 Right-click **Download with ODM**
* 📂 Download categories and custom save folders
* 🦀 Built with Rust
* ⚛️ React UI
* 🖥 Tauri desktop architecture
* 🔓 AGPL-3.0 open-source license

⭐ **Repository**

https://github.com/muzammilijaz/odm
